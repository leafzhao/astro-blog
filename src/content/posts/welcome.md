欢迎来到 Leaf Zhao 的个人小站 👋

这里是我记录**生活**的地方：写一些日常随笔、读书和旅行的感受，也会把随手拍下的照片整理成相册，放在 [照片](../../photos/) 页面。

学术相关的内容（论文、项目、简历等）会放在我的 [学术主页](https://leafzhao.github.io/)，这里则更随意一些。

## 这个网站是怎么搭的

- 基于 [Astro](https://astro.build) 和 [Fuwari](https://github.com/saicaca/fuwari) 主题；
- 文章用 Markdown 写，放在 `src/content/posts/` 目录；
- 照片按相册放在 `src/assets/photos/<相册名>/`，构建时会自动压缩成 WebP 并去掉 EXIF 信息；
- 通过 GitHub Actions 自动部署到 GitHub Pages。
